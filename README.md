# MCP Project Scaffold

This workspace includes a minimal Python scaffold with:

- `server.py` as the entry point
- `db.py` for SQLite setup
- `tools.py` for shared utility helpers
- `.env` for local configuration

## Run

1. Create and activate a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Run `python server.py`.

## Notes

The project currently uses only the Python standard library. The `requirements.txt` file is present so dependencies can be added later without changing the layout.
